# Image credits

The four sample images bundled in this folder (`morning.jpg`, `noon.jpg`, `evening.jpg`, `night.jpg`) were sourced from [Pexels](https://www.pexels.com/) during early development.

Pexels images are available under the [Pexels License](https://www.pexels.com/license/) — free to use for commercial and non-commercial purposes, with photographer credit requested but not strictly required. These specific files were downloaded before per-image attribution tracking was added to the pipeline, so individual photographer names are not preserved here.

If you recognize one of these images as your own work and would like proper attribution or its removal, please open an issue at https://github.com/rps321321/elysium-wallpaper/issues — we'll credit you or replace the file promptly.

Going forward, every image the app fetches via Openverse ships with a `.attribution.json` sidecar containing license + creator + source URL. Pexels fetches carry the photographer name in the app UI.
